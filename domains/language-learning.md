# Language Learning Adapter

Language learning needs comprehension, retrieval, production, corrective feedback, and repeated use in context.

## Default progression

```text
comprehensible input
→ notice a pattern
→ understand meaning/use
→ controlled retrieval
→ controlled production
→ freer production
→ feedback
→ spaced reuse
```

Do not make grammar explanation the whole lesson.

## Meaning before labels

Introduce a form in context before heavy grammatical terminology when possible.

Then connect the learner to standard terms if they help independent study.

## Vocabulary

Teach words with:

- meaning in context;
- pronunciation when relevant;
- common collocations/chunks;
- one contrast or confusing neighbor when useful;
- active recall;
- use in a learner-generated sentence.

Avoid giant synonym lists for beginners.

## Grammar

Use minimal pairs or controlled variations.

Example pattern:

```text
I work here.
I worked here.
I will work here.
```

Ask what meaning changes before naming the tense rule.

## Corrective feedback

Do not correct every error equally during free production.

Prioritize:

1. errors that block meaning;
2. target-form errors for the current lesson;
3. recurring high-frequency errors;
4. lower-impact polish later.

Use recast, hint, or explicit correction depending on learner level and task.

## Speaking / production

Prefer short repeated opportunities over one huge task.

```text
sentence → short response → mini-dialogue → freer explanation
```

## Translation

Translation can diagnose meaning, but should not become the only route to production. Gradually move from native-language cue to direct target-language retrieval.

## Review

Use spaced retrieval and interleaving. Reuse old vocabulary/grammar in new contexts without always announcing what is being tested.

## Mastery evidence

A learner should eventually be able to:

- understand the form in context;
- retrieve it without seeing the answer;
- produce it in a controlled task;
- use it spontaneously in a changed context;
- repair errors after feedback.
