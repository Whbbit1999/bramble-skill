# Mathematics Teaching Adapter

Mathematics requires more than getting the right answer. Separate conceptual understanding, procedural fluency, reasoning/proof, and transfer.

## Default sequence

For a new mathematical idea, prefer:

```text
concrete/numeric case
→ visual or geometric intuition when useful
→ pattern/relationship
→ formal definition/notation
→ worked example
→ guided variation
→ independent problem
→ explanation/proof/boundary
→ transfer
```

## Multiple representations

Move deliberately among representations:

- words;
- numbers;
- symbols;
- graphs/geometry;
- tables;
- transformations or processes.

A learner who can manipulate symbols but cannot connect them to meaning may have procedural fluency without conceptual understanding.

## Definitions

Do not hide formal definitions forever. Delay them until the learner has enough intuition to attach meaning to the symbols.

Then make each part of the definition earn its place by showing what would fail without it.

## Worked examples and fading

For procedures:

```text
fully worked example
→ explain why each step is legal
→ one missing step
→ fewer prompts
→ independent problem
→ changed representation/context
```

Avoid giving five nearly identical exercises after mastery is clear.

## Symbol sense

When notation blocks understanding:

1. read the expression aloud in plain language;
2. identify what each symbol represents;
3. substitute a concrete value or draw a picture;
4. return to the symbolic form.

## Proof and reasoning

Do not teach proof as polished text first.

Use:

```text
what must be shown?
→ what is known?
→ possible bridge/lemma
→ test with examples/counterexamples
→ construct argument
→ polish proof
```

Distinguish:

- example as intuition;
- counterexample as refutation;
- proof as general justification.

## Error diagnosis

Common categories:

- notation misunderstanding;
- arithmetic/algebra slip;
- wrong procedure selection;
- missing prerequisite;
- invalid transformation;
- hidden assumption;
- concept/procedure disconnect;
- overgeneralization from examples.

A wrong final number does not tell you which category occurred. Inspect the reasoning.

## Questions that reveal understanding

Useful prompts:

- “为什么这一步可以这样变形？”
- “如果参数变大，图像会怎样变化？”
- “不用公式，你会怎么描述这个量？”
- “这个结论对所有情况都成立吗？能找反例吗？”
- “这道题为什么应该用这个方法，而不是另一个？”

## Applied mathematics

When formulas model reality, name:

- variables and units;
- assumptions;
- valid range;
- what is being approximated;
- what a result means in context.

## Mastery evidence

Prefer a combination such as:

```text
solve + explain
```

or:

```text
represent in two forms + transfer to a new problem
```

For proof-oriented topics, require reasoning rather than answer-only correctness.
